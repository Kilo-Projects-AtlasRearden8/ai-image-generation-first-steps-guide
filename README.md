# AI Image Generation First Steps Guide

A beginner-friendly manual (Markdown docs + static HTML site) on making AI images for free: choosing models, writing prompts, aspect ratios, local versus cloud, copyright basics, safety filters, and a printable prompt checklist. Plain English, step by step, no art experience needed.

Written by **Dylan Asdale** of **Asdale Dynamics, LLC** — a registered nurse turned AI author who explains AI "like a friend would": plain English, step by step, never condescending.

`docs/` — Markdown source for the manual:

| Page | What it covers |
|------|----------------|
| [index.md](docs/index.md) | Welcome and how to use the guide |
| [choosing-models.md](docs/choosing-models.md) | Picking a free image model |

## Start here

If you have never made an AI image before, work through these pages in order:

1. [Choosing models](docs/choosing-models.md) — pick a free tool to start with
2. [Writing prompts](docs/writing-prompts.md) — describe what you want to draw
3. [Aspect ratios](docs/aspect-ratios.md) — pick the right shape for your image
4. Make your first image in your chosen tool
5. [Prompt checklist](docs/prompt-checklist.md) — print this and use it every time

Then read [Local vs cloud](docs/local-vs-cloud.md), [Copyright basics](docs/copyright-basics.md), and [Safety filters](docs/safety-filters.md) whenever you want to go deeper.

## Quick start

You need [Node.js](https://nodejs.org). Then:

```bash
npm install
npm run build
```

This reads the Markdown files in `docs/` and writes HTML files to `site/`. Open `site/index.html` in your browser to read the guide.

To run the tests:

```bash
npm test
```

To syntax-check the build script:

```bash
npm run lint
```

## Printing the checklist

The [prompt checklist](docs/prompt-checklist.md) is designed to print on one page. Open `site/prompt-checklist.html` in your browser and choose File > Print. The navigation, header, and footer are hidden when printed so you get a clean worksheet.

## Who this is for

Anyone who wants to make AI images without paying for a subscription. Writers, small-business owners, healthcare workers learning AI (education only — never medical advice), and beginners of every kind. No prior art or programming experience required.

## Local-first, privacy-first

This guide and the site it builds are **local-first**: you can read, build, and host everything on your own computer. We never ask for API keys, passwords, or personal data, and you should never paste them into this guide or into any AI image tool unless you fully understand what you're doing.
