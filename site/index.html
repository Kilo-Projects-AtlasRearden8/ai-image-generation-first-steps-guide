Welcome

Making AI images is one of the most fun ways to play with artificial intelligence. You type a few words, and a computer draws a picture for you. You do not need to know how to draw, paint, or use fancy software. You do not even need to spend money.

This manual walks you through making AI images for free, step by step, in plain English. It is written by Dylan Asdale of Asdale Dynamics, LLC — a registered nurse turned AI author who explains AI "like a friend would": plain English, step by step, never condescending.

How to use this manual

If you have never made an AI image before, work through these pages in order:

  1. Choosing models — pick a free tool to start with
  2. Writing prompts — describe what you want to draw
  3. Aspect ratios — pick the right shape for your image
  4. Make your first image in your chosen tool
  5. Prompt checklist — print this and use it every time

Then read Local vs cloud, Copyright basics, and Safety filters whenever you want to go deeper.

Read it in order, or jump to the page you need right now. Every page keeps things simple. If a word feels unfamiliar, look it up in context — there is no test at the end.

You can read this manual as Markdown files in docs/, or as a finished website in site/. The website is built from the Markdown files with npm run build, so you never need to edit site/ by hand.
